- 🔀 Shuffle - Pretty self explanatory, shuffles songs innit...
- 🔁 Song looper - Loops songs!
- 🔊 Volume slider - Easy In-App audio control
- 🎼 Current playlist viewer - Allows you to see upcoming songs and reorder them by dragging them
- 📌 Pin window - Pin the window ontop of others which goes well with:
- 🪟 Scalable window - Have as much or as little info as you want, go from a full Spotify like view to a minimal one.

## How to Install:

### Prerequisites:
- You need vlc to be installed on your computer
- Preferably have some music to play 

### Option 1, The easy way:
> ⚠️ **Note for Windows Users**: 
> Because the `.exe` was built with PyInstaller and is unsigned, 
> Windows Defender will most likely show a popup saying "Windows protected your PC". 
> 
> To run it: Click **More info** -> **Run anyway**. 
> You can also inspect the full source code in `PyFi.py`!
1. Download the .exe
2. Run it
3. You can now listen to your songs and stick it to the man, well done!!

### Option 2, The manual method:
1. In your preferred editor run: git clone https://github.com/Choc0latesauce/PyFi.git
2. Then: cd PyFi.py
3. Install the dependencies with: pip install -r requirements.txt
4. Now run PyFi with: python pyfi.py
